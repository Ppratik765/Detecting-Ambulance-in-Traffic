# Audio-Visual Sensor Fusion for Emergency Preemption

This repository contains the end-to-end pipeline and dashboard for detecting ambulances in traffic using visual and acoustic sensor fusion.

## Project Structure

- `colab/`: Contains the backend Google Colab pipeline for model training and inference.
- `frontend/`: A Vite-powered vanilla JS dashboard for real-time visualization of the fusion telemetry.

## Backend (Google Colab)

The `colab/fusion_pipeline.ipynb` notebook handles:
1. Downloading datasets from Kaggle.
2. Training a YOLOv8 vision model on ambulance images.
3. Training a 3-layer 2D CNN acoustic model on siren Mel-spectrograms.
4. Fusing the probabilities via Late Bayesian Fusion.
5. Exporting `telemetry.json` and the processed video feed.

### How to run the backend:
1. Upload `colab/fusion_pipeline.ipynb` to Google Colab.
2. Provide your actual Kaggle API credentials and dataset names for the vision and audio datasets inside the notebook.
3. You will need to implement the specific PyTorch DataLoader logic depending on the exact structure of your Kaggle datasets.
4. Run the notebook to generate `ambulance_feed.mp4` and `telemetry.json`.
5. Place both files in the `frontend/public/data/` directory.

## Frontend Dashboard

The frontend dashboard provides a split-screen command center UI to visualize the telemetry generated by the Colab pipeline.

### Running Locally
```bash
cd frontend
npm install
npm run dev
```

The frontend uses Vite to serve the local assets. It looks for `/data/ambulance_feed.mp4` and `/data/telemetry.json` in the `public` directory.
